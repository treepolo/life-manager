# E2-2 臺灣人口金額分布模型

## 範圍

E2-2 只建立可重建的統計模型與 generated model，不修改 Life Manager 首頁、財務欄位、同步資料或 D1 schema；E2-3 才把模型接進產品。固定比較母體為 23,299,132 人。`peopleBelow(x)` 使用嚴格小於語意；`estimatedPeopleAtIntegerAmount(x)` 回傳估計落在該 1 元區間的人數。

```text
來源資料
  -> data/taiwan-distributions/*.json
  -> scripts/taiwan-distributions/model.mjs
  -> npm run model:taiwan
  -> data/taiwan-distributions/generated/*.json
  -> E2-3 runtime
```

App runtime 不連線抓政府或 Forbes 網頁，也不在執行時重新擬合。

## 月收入

主要資料為行政院主計總處《113年家庭收支調查報告》第 6 表。所得收入者官方總數 16,753,266 人；完整年度所得級距除以 12 轉為月均所得。固定比較母體扣除所得收入者後的 6,545,866 人保留為 0 元離散質量。

擷取的 41 個所得分組合計比官方總計多 2 人，因此 build 使用 deterministic largest-remainder normalization 校正到 16,753,266。封閉級距以分段指數密度表示，級距人口為硬約束；最高 `2,500,000 元／年以上` 開放級距以頂端三個官方 survival anchors 擬合 Pareto 尾端。官方所得收入者平均與中位所得只作 sanity check。

## 個人等值淨資產

### 原始家庭資料

主體是行政院主計總處 2021 年底家庭財富分配，財富使用官方淨值定義「非金融資產 + 金融資產 - 金融性負債」。家庭財富 D1-D9 門檻為 143、319、490、677、894、1,171、1,547、2,134、3,391 萬元；五等分位平均為 76.7、492.7、906.3、1,580.7、5,133.2 萬元。

家庭資料不能直接拿全臺人口做個人排名。模型使用同一份國富統計中的「家庭財富十分位 × 可支配所得十分位」100 格聯合家數，再配 2021 家庭收支調查所得五等分位平均家庭人數 `1.62 / 2.30 / 2.95 / 3.52 / 4.03`。每個所得五等分位的家庭人數套用到對應兩個所得十分位，據此估算每個財富十分位的平均家庭人數與估計人口。

各財富十分位估計人口最後使用 largest-remainder normalization 正規化到全臺 23,299,132 人。因此財富十分位在「家庭」層級各約 10%，轉成「人」之後不再各占固定 10%。

### 家庭金額轉個人等值金額

D1-D9 每個家庭財富門檻使用門檻兩側財富十分位的聯合家庭結構，換算成相鄰兩層合併的平均家庭人數，再將家庭門檻除以該平均戶量。五等分位平均則各自使用該兩個財富十分位合併後的平均家庭人數換算。這些值是「個人等值淨資產」估計，不是政府直接觀測的個人財富。

最低財富層保留負淨資產，用以 D1 為上界的反向指數尾端表示。第 20%-80% 每兩個十分位區間用分段指數密度，使轉換後五等分位平均精確回到來源錨點；80%-90% 延續前一組局部斜率。

### 最高財富尾端

Forbes 2026 Taiwan's 50 Richest 用於極高端約束。名單估值基準日為 2026-05-22，入榜門檻 US$2.2B；Forbes 明確表示榜單混合個人與家族共同財富。模型保留 50-entry cutoff 作為存活人數錨點；對明確列出多名親屬的已收錄條目，只有在推導「個人等值最大錨點」時才等分共同財富。以目前收錄條目計算，最大個人等值錨點為 Pierre Chen 的 US$18.2B，按 31.568 NTD/USD 為 NT$574,537,600,000。

模型同時計算由轉換後 D5-D9 survival anchors 擬合出的 Pareto alpha，作為尾端形狀診斷；它不被當成 D9 以上的硬外推條件。原因是若把該 alpha 直接延伸到高額區間，會與主計總處最高 20% 平均及 Forbes 端點產生無法同時滿足的數學衝突。實際 D9 以上尾端因此採三段 capped survival power law，數值校準優先滿足直接來源硬錨點：D9 人口、轉換後最高 20% 平均、Forbes 50-entry cutoff、最大個人等值錨點。

## 驗證

`npm run model:taiwan:check` 與單元測試會驗證：

- 兩個模型人口總數精確等於 23,299,132。
- 收入所得收入者精確等於 16,753,266；0 元質量精確等於 6,545,866。
- 所有累積人口單調不減，任意整數 1 元區間的估計人口不可為負。
- 收入正所得平均與官方所得收入者平均誤差低於 1%。
- 財富 100 格聯合家數確實轉成分財富十分位戶量與人口，十層人口合計精確回到 23,299,132。
- 財富五個五等分位平均在個人等值轉換後全部回到來源錨點。
- 負淨資產左尾存在，0 元以下估計人口為正且低於全體 10%。
- Forbes cutoff 處約剩 50 人；最大個人等值錨點處剩 1 人。
- committed generated JSON 必須和 raw data + model code 的重建結果完全一致。

## 已知限制

收入端把「全體人口 - 所得收入者」集中到 0 元，是低收入端近似。資產端從家庭轉成個人依賴財富與所得聯合分布及分所得層平均戶量，無法知道每個家庭內資產真正由哪一位成員持有；因此輸出應稱為「個人等值淨資產估計」。Forbes 尾端的共同家族財富拆分同樣是假設，而且目前 repository 只保留模型實際使用及公開核對過的 Forbes 條目與端點，不宣稱已重建 Forbes 50 名每一筆個人財富。這些模型都不是政府逐元個人微觀資料。
