# 產品需求

本文件自 2026-08-30 起取代舊版人生管理器的產品需求。舊版領域、事業、社群、投資、期限、通用指標、事件、外部平台整合與複雜財務功能均已退役；Git 歷史保留其舊規格。

## 產品原則

- PROD-001：產品只處理每日任務、任務分類、固定月收入、積蓄與成果視覺化。
- PROD-002：維護功能與產品功能分層；離線同步、Cloudflare Access、PWA、安全更新、備份／資料庫維護與免費額度保護不因產品瘦身而失效。
- PROD-003：新版產品資料模型獨立建立，不沿用舊任務排程、舊財務交易或通用指標模型。
- PROD-004：介面只保留首頁、每日任務、設定三個主要入口。
- PROD-005：正式資料庫舊表只能在所有裝置待同步為 0、完成遠端備份且新版驗證完成後，以新的 cleanup migration 移除。

## 每日任務

- TASK-001：每日任務每天都需要完成；跨入新曆日後重新顯示為未完成。
- TASK-002：每日任務只有名稱、敘述、所屬分類三個使用者欄位。
- TASK-003：任務分類只有名稱、敘述；不另外建立類型、標籤、優先級、排程或延期概念。
- TASK-004：同一任務在同一個 Asia/Taipei 曆日最多有一筆有效完成紀錄；完成後可以撤銷。
- TASK-005：封存任務或分類後不再出現在今日清單，但歷史完成紀錄保留；封存項目可恢復。
- TASK-006：成果統計以任務分類累積旗下每日任務的有效完成次數。

## 財務進度

- FIN-001：保存目前的目標固定月收入與目標積蓄，兩者皆可手動修改或清空。
- FIN-002：實際固定月收入以日期化歷史紀錄保存，使用者可新增、修改與刪除。
- FIN-003：實際積蓄以日期化歷史紀錄保存，使用者可新增、修改與刪除。
- FIN-004：目前固定月收入與目前積蓄皆由截至今天日期最新的有效歷史紀錄推導，不另存第二份目前值。
- FIN-005：同一天可有多筆實際紀錄；圖表與目前值採該日最後建立且仍有效的一筆。
- FIN-006：固定月收入不可為負數；積蓄允許負數以表示淨負債；第一版幣別固定新台幣且以整數元保存。

## 首頁與視覺

- UI-001：首頁優先顯示今日每日任務與完成狀態。
- UI-002：首頁顯示目前固定月收入／目標固定月收入、目前積蓄／目標積蓄。
- UI-003：首頁顯示各任務分類從第一筆有效資料到今天的累積完成次數曲線。
- UI-004：首頁顯示積蓄歷史曲線與固定月收入歷史曲線；財務資料使用階梯語意延伸到今天。
- UI-005：採兒童蠟筆手繪與紙張風格，但日期、數值、圖例、座標軸、單位、完成控制與表單必須可辨識。
- UI-006：桌機、平板、320／390 像素手機都不得產生水平溢出；PWA 更新提示不得遮住手機底部導覽與同步狀態。

## 離線、同步與安全

- OFF-001：所有新版產品寫入都支援 IndexedDB 離線保存與 outbox；恢復連線後送至 D1。
- OFF-002：同一實體連續離線修改應合併或依序安全處理，不得因舊 baseVersion 造成自我衝突。
- OFF-003：離線刪除使用 tombstone `deletedAt` 語意；尚未同步的新資料若又刪除，可取消建立而不製造無效遠端操作。
- OFF-004：跨裝置版本衝突保留本機與伺服器版本供處理，不採無提示最後寫入者勝出。
- OFF-005：PWA 更新只有在 outbox 為 0 時允許安全接管；更新不得要求清除 IndexedDB 才能使用。

## 維運

- OPS-001：繼續使用 Cloudflare Worker、Static Assets、D1 與 Cloudflare Access，不建立新的會員系統。
- OPS-002：保留 D1／Workers 免費額度防線；已退役的 YouTube、Instagram、Resend、Push 與 Firstrade 專屬額度或排程程式不再執行。
- OPS-003：`0001`～`0010` migration 視為不可修改歷史；新版從 `0011` 往後增加。
- OPS-004：所有變更在獨立分支先通過 lint、TypeScript、單元測試、Worker/D1 測試、build、Playwright、production scan 與需求覆蓋檢查。
- OPS-005：在未完成正式 D1 備份與所有裝置 outbox=0 驗證前，不部署會 drop 舊產品表的 migration。
