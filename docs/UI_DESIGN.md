# 介面設計

## 導覽

只保留三個主要入口：首頁、每日任務、設定。桌機使用左側導覽；窄螢幕改用底部三項導覽。同步狀態一直可見，但不搶主要內容。

## 首頁

首頁依序顯示：

1. 今天日期與今日完成數。
2. 今日每日任務清單；整列可切換完成／撤銷。
3. 固定月收入與積蓄的目前值／目標。
4. 快速新增今天的固定月收入或積蓄紀錄。
5. 任務分類累積完成次數圖。
6. 積蓄變化圖。
7. 固定月收入變化圖。

## 每日任務

新增分類只有名稱、敘述；新增任務只有名稱、敘述、分類。管理既有項目只提供編輯、封存、恢復。不加入優先級、日期排程、估時、標籤、延期或其他欄位。

## 設定

- 編輯兩個財務目標。
- 新增固定月收入／積蓄歷史。
- 歷史每筆可修改日期與金額、可刪除；刪除前有確認。
- 顯示待同步筆數、同步錯誤與手動同步入口。

## 蠟筆手繪風格

- 暖色紙張背景與微弱紙纖維紋理。
- 粗細略不均的深色邊框、不完全規則的卡片角與輕微旋轉。
- 黃、紅、藍、綠、紫等蠟筆色用於重點與圖表線。
- 圖表可加入輕微 SVG 位移來模擬手繪，但座標、日期、圖例、tooltip、單位與數值不得省略。
- 核取框要像手畫方框，但可操作區域使用整列按鈕，確保手機容易點擊。

## 響應式

至少驗證 320、390、768、1366、1920 像素寬。所有尺寸禁止水平溢出。手機底部導覽上方保留同步列；PWA 更新提示固定在同步列之上，不能遮住導覽。

## 無障礙與穩定性

表單使用 label；主要導覽有 aria-label；圖表區有可讀標題。`prefers-reduced-motion` 時移除裝飾性 transform／transition。手繪效果不能讓字體、數值或控制項變得難辨識。
